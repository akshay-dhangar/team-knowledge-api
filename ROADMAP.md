# team-knowledge-api: seven-day MVP

Goal: Build a citation-aware knowledge API for remote engineering teams.

Status: active. The initial core component is implemented; the full MVP is not.

- [x] Day 1: Text chunking with overlap and source metadata.
- [x] Day 2: Add document ingestion and persistence.
- [ ] Day 3: Implement lexical retrieval baseline.
- [ ] Day 4: Add pluggable embeddings and vector retrieval.
- [ ] Day 5: Return cited answers through an API.
- [ ] Day 6: Test access boundaries and retrieval quality.
- [ ] Day 7: Demonstrate a small team knowledge corpus.

## Definition of done

- A documented local command runs the scoped end-to-end example.
- Meaningful positive and failure-path tests pass locally and in CI.
- README distinguishes implemented features, mocks, measured results, and limitations.
- Example inputs and outputs are reproducible.
- A short demo script and evidence-based LinkedIn draft are saved locally.
- Real model quality is not claimed without a live evaluation.

Seven days is a target. Reduce scope or record unfinished work explicitly; never mark a project complete merely because its week ended.
